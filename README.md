# SpendLens AI

Stop overpaying for AI tools. Audit your Cursor, Claude, ChatGPT, Copilot, and API spend in under 60 seconds.

## Summary
SpendLens AI is a free web app that helps startup founders and engineering managers find overspending in AI tools like Cursor, Claude, ChatGPT, GitHub Copilot, OpenAI API, Anthropic API, Gemini, and Windsurf.

## Trade-offs
1. **Rule-based Audit Engine vs. AI Math**: I explicitly chose to build a deterministic, rule-based audit engine using TypeScript instead of relying on an LLM to calculate savings. While an LLM might seem more "advanced," it is prone to hallucinating prices and inconsistent math. By using hardcoded, verified pricing rules, I ensure 100% accuracy and transparency—crucial for a tool dealing with financial spend.
2. **LocalStorage Persistence vs. Database Auth**: To keep the friction to entry near zero, I implemented form persistence using `localStorage` instead of requiring a login. This allows users to start their audit immediately and return to it later without the hurdle of creating an account, which significantly improves conversion rates for a top-of-funnel lead magnet.
3. **Simplified Plan Pricing**: I chose to focus on the most common 8-10 AI tools and their primary tiers rather than trying to build a comprehensive database of every niche AI tool. This allowed me to verify every single pricing number manually and provide a higher quality of recommendation for the tools that actually drive 90% of startup spend.
4. **Resend over AWS SES**: I opted for Resend due to its superior developer experience and native Next.js integration. While SES might be slightly cheaper at massive scale, Resend allowed for faster implementation of beautiful, React-based email templates that match the premium aesthetic of the brand.
5. **Deterministic Summary Fallbacks**: Every AI-generated summary has a robust, data-backed deterministic fallback. I prioritized reliability over "creativity"—if the LLM API is slow or fails, the user still gets a high-quality, numbers-accurate summary paragraph generated by the system.
